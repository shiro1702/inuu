# Приоритизация функций

Оценка по трём осям: **скорость реализации** (1–10, где 10 = долго), **ценность для пользователя**, **потенциал монетизации**.

Реализация в рамках **Nuxt 3 + Supabase** ([11-tech-stack.md](./11-tech-stack.md)).

## Рекомендуемая последовательность внедрения

### Волна A — «Умный гид» (недели 1–4)

1. Миграции Supabase + `cities` + Nuxt middleware редиректа.
2. `pages/[city_slug]/` — events, venues, главная сетка.
3. Seed подборок и 50+ карточек.
4. Tailwind, SSR/SEO, деплой Vercel/VPS.

### Волна B — «Привычка» (месяц 2)

5. Telegram Login + избранное.
6. Stories на главной.
7. Отзывы (упрощённые).
8. ТГ-канал ↔ ссылки на события.

### Волна C — «Деньги» (месяц 3)

9. Оплата + запись на события (билеты).
10. Beauty: профили, слоты, лист ожидания.
11. Горящие окошки.
12. Первые платные размещения / баннеры.

### Волна D — «Сезон Байкал» (месяц 4–5, к лету)

13. Каталог турбаз / глэмпингов.
14. Тендерная заявка на отдых.
15. Фото / туры (лёгкая витрина).

### Волна E — «Экосистема» (месяц 6+)

16. Кондитеры (полный ЛК).
17. Локальные бренды (витрина).
18. Кросс-промо, рандомайзер, рекламный кабинет.

## Что сознательно откладываем

| Функция | Причина |
|---------|---------|
| Парсинг новостных RSS | Контент от редакции |
| Широкий парсинг всех внешних источников без whitelist | Риск дублей, спама и юридики |
| Раздел «для предпринимателей» | Нет фокуса на MVP |
| Полный маркетплейс с корзиной | Юридика, остатки, логистика |
| Reels-лента | Дорого, не дифференцирует на старте |
| Нативное iOS/Android | Web + Telegram Web App достаточно |
| YClients API | Только при запросе от салонов |
| October CMS | Не используется — только Nuxt + Supabase |

## KPI по волнам

| Волна | Метрики успеха |
|-------|----------------|
| A | Время на сайте >40 с, глубина >3 стр., 50+ карточек |
| B | 10% регистраций от визитов, клики по stories |
| C | 20+ оплаченных записей/нед, 5+ платящих партнёров |
| D | 10+ лидов на турбазы / нед в сезон |
| E | 100+ мастеров, положительная unit-экономика рекламы |
