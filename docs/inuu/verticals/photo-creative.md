# Вертикаль: Фото и креатив

Фотостудии, фотографы, связка с **beauty** (макияж) и **локальными брендами** (образ). Этап 4–5.

---

## Для клиента

### Фотостудии

- Каталог студий по стилю интерьера (лофт, этно, минимализм).
- **Аренда по часам** — слоты (если есть CRM) или заявка «узнать свободные часы».
- Галерея, цены, адрес.

### Фотографы

- Портфолио по стилю: street, studio, love story, **Байкал**.
- Пакеты: «1 час / 2 часа + обработка N фото».

### Конструктор «Фотодень»

Пакет в одной покупке (или заявке):

1. Визажист / мастер ([beauty](./beauty.md)).
2. Аренда студии.
3. Фотограф.

Скидка 10% при бандле — монетизация кросс-промо.

---

## Для партнёра

- Профиль, портфолио, календарь (упрощённый).
- Заявки с сайта / WhatsApp.
- Рекомендации брендов одежды для съёмки (платное место в карточке).

---

## Связь с туризмом

- «Фотосессия на Байкале» — отдельная категория в [tourism-baikal](./tourism-baikal.md).
- Коллаб: турбаза + фотограф = контент для stories и SEO.

---

## Техника

- Переиспользование `Booking` type=studio_slot.
- Медиа: тяжёлые галереи — lazy load, WebP.
- Видео room tour — embed или mp4 ≤5 MB.

---

## MVP

1. Только каталог студий и фотографов + WhatsApp.
2. Пакет «фотодень» — статичная подборка из 3 карточек с одной формой заявки.
3. Календарь и оплата — после отклика рынка.

---

## Метрики

- Заявок на съёмку / месяц.
- CR с beauty (клиент записался на макияж → предложена студия).
- Партнёров в каталоге (цель: 10–15 на город).
