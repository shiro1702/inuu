# Вертикаль: Туризм и Байкал

Турбазы, глэмпинги, авторские туры. **Высокий средний чек**, сильная **сезонность** (май–сентябрь). Приоритет к летнему сезону.

География: Улан-Удэ как хаб + **Максимиха, Горячинск, Энхалук**, острова, «первая линия».

---

## Для клиента

### Каталог

- Карточки с **большими hero-фото** (Vue carousel / галерея на Tailwind).
- **Фильтры вайба:**
  - вид на озеро / лес
  - семейный / для компании
  - баня / чан
  - с питомцем
  - бюджет ₽ / ₽₽ / ₽₽₽

### Бронирование (этапы)

| Этап | Механика |
|------|----------|
| MVP | Кнопка **«Узнать свободные даты»** → форма → WhatsApp/TG владельцу |
| Рост | **Тендерная заявка** (см. ниже) |
| Зрелость | Календарь занятости (только при CRM у партнёров) |

**Не делать сразу:** синхронизация занятости со всеми базами — высокая стоимость разработки.

### Городские маршруты (брейншторм 30.05.2026)

- Монетизация: спонсорская точка в маршруте (кофейня по пути).

## Тендер на отдых (killer B2B)

### Форма клиента

- Даты заезда/выезда.
- Количество гостей (+ питомец).
- Бюджет на человека.
- Пожелания: баня, первая линия, тишина и т.д.

### Обработка

- Заявка в **закрытый Telegram-канал** партнёров-турбаз.
- Первый отклик «Заберу» или ручное распределение редакцией.
- Статусы: `new` → `assigned` → `closed_won` / `lost`.

### Монетизация

- Фикс за лид (300–1500 ₽).
- % со сделки при консьерж-модели.
- Платные места в подборке «Топ-5 с чаном».

## Консьерж (развилка при сложном бронировании)

Клиент пишет: «Найдите дом на 6 человек» → платформа звонит базам → предоплата с клиента + комиссия.

## Сезонная стратегия

| Период | Акцент |
|--------|--------|
| Окт–апр | Минимальный каталог, SEO-статьи «куда поехать летом» |
| Май–июн | Тендер + подборки, реклама |
| Июл–авг | Пик лидов, stories с дрона/снега |
| Сент | «Последние окна сезона» |

Зимой качаем **beauty** и **городские события**, летом — **турбазы**.

---

## Гипотеза и развилка

**H:** Владельцы платят за лиды; пользователи предпочитают одну форму множеству звонков.

| Исход | Действие |
|-------|----------|
| ✅ | Масштабировать тендер, поднять цену лида |
| ❌ Мало заявок | SEO-подборки + только реклама |
| ❌ Не платят | Бесплатный каталог + монетизация только «Топ-N» |

## Метрики

- Заявок / неделя (сезон).
- CR просмотр карточки → отправка формы.
- % закрытых сделок (опрос партнёров).
- Средний чек сделки (для % модели).
