# Вертикаль: Кондитеры

Самозанятые кондитеры: **тортики и еда на заказ** + **готовая продукция**. Этап после beauty или параллельно (месяц 2–3).

---

## Для клиента

### Каталог кондитеров

- **Фильтры:** тип продукции, рейтинг, срок изготовления, цена.
- **Поиск** по ближайшей свободной дате выдачи.
- **Сортировка:** оценка, дата.

### Заказ «Под заказ»

- Конструктор: начинки, оформление, вес.
- **Загрузка референса** (фото).
- Комментарий к заказу.
- Дата и время выдачи / доставки.

### Готовая продукция

- Категории (торты, капкейки, наборы).
- **Глобальный поиск** по названию и тегам.
- Выбор **количества в упаковке**.
- Быстрый заказ при наличии.

### Выкуп

| Режим | Поведение |
|-------|-----------|
| Самовывоз | Слот времени забрать |
| Доставка | Адрес, окно доставки |
| Подтверждение | Статусы: ожидает → готов → выдан |

### Оплата

- Онлайн при заказе; **возврат** по правилам отмены.
- Прозрачные сроки изготовления.

---

## Для кондитера (ЛК)

| Модуль | Функции |
|--------|---------|
| Заказы | Список всех + **календарь** на месяц/неделю со временем выдачи |
| Готовая продукция | CRUD, **быстрое заполнение** из ЛК (пакетные поля, копирование) |
| Остатки | Текущий остаток, сколько выкупили |
| Финансы | Баланс, **доступно к выводу**, история выплат |
| Под заказ | Шаблоны начинок/декора |
| Уведомления | Новый заказ, отмена |

---

## Отличия от beauty

| Аспект | Beauty | Кондитеры |
|--------|--------|-----------|
| Слот | Фиксированная длительность услуги | Дата выдачи + lead time |
| Товар | Услуга | Продукт + кастом |
| Склад | — | Остатки готовой продукции |
| Выплаты | После визита | После выдачи / холд |

---

## Монетизация

- Реклама в категории «Сладкое».
- Подписка за расширенный каталог SKU.
- Комиссия с онлайн-оплаты (позже).

---

## MVP-упрощение

1. Только «под заказ» без остатков.
2. Заявка → WhatsApp кондитера.
3. Полный цикл с оплатой и календарём — этап 5.

---

## Риски

- Нет учёта остатков → негатив «заказали, нет в наличии» → премодерация или ручное «в наличии сегодня N шт».
- Самозанятые и чеки — информировать, касса не в MVP.
