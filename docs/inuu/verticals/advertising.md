# Вертикаль: Реклама и рекламодатели

Основной поток монетизации на средней дистанции.

---

## Типы размещения

| Placement | Формат | Где |
|-----------|--------|-----|
| `home_hero` | Баннер / carousel | Главная города |
| `category_top` | Карточка promoted | Верх beauty / events / tourism |
| `native_list` | 5-я позиция в подборке | Editorial lists |
| `story_slot` | Первый кружок | Stories bar |
| `telegram_digest` | Пост в канале | Омниканал пакет |

Все кампании привязаны к **`city_id`**.

---

## Кабинет рекламодателя

### MVP (ручной + админка)

- Заявка на размещение через форму / менеджера.
- Загрузка креатива в Supabase Storage + запись в `ad_campaigns`.
- Ручной старт/стоп кампании.

### Фаза 2 (self-service)

- Регистрация рекламодателя.
- Выбор placement, дат, бюджета.
- Превью на макете.
- Статистика: impressions, clicks, CTR.
- Счета и акты (экспорт / интеграция позже).

---

## Таргетинг (по мере роста базы)

- Категории интересов пользователя.
- Гео: район города (если есть в профиле).
- Избранное: **не персональные данные в открытую** — только агрегированные сегменты.

### Платные рассылки B2B

- «Скидка в салоне X» пользователям с интересом beauty + город.
- Лимит: N сообщений / пользователь / месяц.
- Opt-in обязателен.

---

## Ценообразование (ориентиры Улан-Удэ)

| Продукт | Ориентир |
|---------|----------|
| Баннер главная / нед | Договорная |
| Топ категории / мес | 3–15 тыс. ₽ |
| Story (1-й слот) / 24ч | 1–5 тыс. ₽ |
| Пакет «выходные» (TG+сайт+story) | 10–25 тыс. ₽ |
| Спонсор подборки | Фикс за слот |

Точные прайсы — после первых 10 продаж.

---

## Отчётность

- UTM на все креативы.
- Счётчик кликов `ad_clicks(campaign_id, user_id?)`.
- Дашборд: ROI для рекламодателя (просмотры → переходы → записи если trackable).

---

## Ограничения

- Премодерация креативов (закон о рекламе, 18+, алкоголь).
- Не смешивать редакционные подборки с рекламой без пометки **«Реклама»**.

---

## Связь с другими вертикалями

- Beauty premium ≈ реклама в `category_top` + stories.
- Турбазы: сезонные пакеты май–август.
- События: спонсор календаря.
