# Вертикаль: События и заведения

**События** (мастер-классы, концерты, лекции) + **venues** (бары, кафе, культурные пространства). Частично готовый код афиши — приоритет **P1** вместе с Instagram-трафиком.

---

## События

### Каталог

- Сетка / masonry (Pinterest-стиль).
- Фильтры: тип (МК, концерт, выставка, спорт), дата, цена, район.
- Календарь на месяц (новый дизайн афиши).

### Карточка события

- Описание, организатор, **место проведения** (`venue_id`).
- Слоты записи / места (как в салоне).
- **Оплата билета** на платформе.
- CTA: «Иду!» / «Купить билет».
- Ссылка из Instagram stories с UTM.

### Запись

- Выбор времени (для МК с несколькими сессиями).
- Лимит мест, счётчик остатка.
- QR-билет в Telegram (фаза 2).
- Функция **«Кто идёт?»** (аватары, FOMO) — позже.

### Организатор (ЛК)

- CRUD событий, цены, квоты.
- Список участников, экспорт.
- Статистика продаж.

---

## Заведения (venues)

### Зачем

Одно место — **много организаторов**: все события в баре X на одной странице.

### Каталог

- Рестораны, бары, кафе, культурные центры.
- Фильтр по **вайбу**: «для свидания», «с ноутбуком», «шумная компания» — не только «кафе/бар».

### Карточка venue

- Адрес, телефон, фото, **мнение редакции** (цитата из обзора IG).
- Ссылка на обзор / embed видео.
- **Предстоящие события** в этом месте.
- Средний рейтинг и отзывы.
- Меню (опционально, без агрегатора доставки на MVP).

### Карта

- Все venues и активные события на карте города.
- Клик → venue или список событий.

### Отзывы

- 1–5 звёзд, текст, фото.
- Премодерация.
- Уведомление заведению.

---

## Stories и контент

Типы stories:

1. **Афиша недели** (редакция).
2. **Событие завтра** (организатор).
3. **Акция в venue** («2 столика», «живая музыка»).

Структура слайда: тип, дата, место, CTA → страница события/venue.

---

## Новости

- **Не парсинг** внешних сайтов на MVP.
- Лента рекомендаций от редакции (Юмжина): куда сходить, обзоры.
- Связка: новость → venue / event.

## Монетизация

- Платное размещение события с оплатой билета.
- Спонсор афиши месяца.
- Реклама venue в подборках.
- Продвижение в stories.

## Техническая связь

```
Event.venue_id → Venue
Venue.city_id → City
Event.organizer_id → Organization
Booking.event_id → Event
Review.entity = venue | event
```
