# Вертикаль: Красота (beauty)

Приоритет **№1** на старте: парикмахеры, маникюр, брови, косметология, визаж.

---

## Для клиента

### Каталог

- Категории услуг: маникюр, стрижки, бьюти-процедуры.
- **Фильтры:** услуга, рейтинг, цена, **ближайшая свободная дата**, район.
- **Сортировка:** название, оценка, дата первой доступной записи.

### Профиль мастера / салона

- Портфолио (фото работ, рилс-стиль — визуал первичен).
- Прайс, описание, отзывы.
- График: мастер может работать в **нескольких салонах** — выбор точки при записи.
- Просмотр свободных часов **по конкретному мастеру**.

### Запись

1. Услуга → дата → время → слот.
2. Оплата (депозит или полная) через эквайринг.
3. Подтверждение + напоминания (email / Telegram).

### Лист ожидания

- Нет мест на выбранную дату → очередь.
- Уведомление при отмене; **30 мин** на подтверждение.
- Опционально: групповая запись, альтернативные мастера.

### Горящие окошки

- Блок на главной города.
- Скидка + таймер; пуш подписчикам категории «маникюр» и т.д.

---

## Для мастера / салона (ЛК)

| Функция | Описание |
|---------|----------|
| Расписание | Слоты, блокировка, привязка к салонам |
| Услуги и цены | CRUD |
| Записи | Календарь, подтверждение/отмена |
| Лист ожидания | Просмотр очереди |
| Горящие окна | Создание через форму или TG-бот |
| Портфолио | Загрузка фото |
| Отзывы | Просмотр, ответ |
| Финансы | Статистика, баланс, вывод (фаза оплаты) |

**MVP для мастера:** упрощённый раздел в `dashboard/` или команды TG/MAX-боту (`/slot`); полный dashboard — по мере роста.

---

## Монетизация вертикали

- Бесплатное размещение 3–6 мес.
- Подписка 500–1000 ₽/мес (визитка + запись + подборки).
- Premium в каталоге + stories.
- Комиссия платформы — после раскрутки.

---

## Технические заметки

- Переиспользовать движок **Booking** из [событий](./events-and-venues.md): слоты вместо мест.
- Интеграция **YClients** — только по запросу салонов (не MVP).
- Fallback: кнопка WhatsApp с prefilled текстом.

---

## Метрики

- Записей / неделя через сайт.
- % слотов заполненных через горящие окна.
- Средний рейтинг мастеров с >5 отзывами.
- Отмены и конверсия waitlist → booking.
