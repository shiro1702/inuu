## Гибрид: Web + Mini App

| Поверхность | Задачи |
|-------------|--------|
| **Web dashboard** | Онбординг ЮKassa, события, волны цен, аналитика, CRM гостей, промоутеры, шаблоны афиш |
| **Mini App «в поле»** | QR-сканнер, live-счётчик входа, ручной поиск билета, выдача прав controller |

**Auth:** Login with Telegram → единый `telegram_id`, без паролей.

---

## Web: ключевые модули

### События

- AI-черновик описания из буллетов (Groq) — опционально.
- Загрузка обложки + кроп.
- Волны цен — визуальный таймлайн ([18](./18-ticketing-full-flow.md)).

### Афиши (не generative AI)

**Layered templates:** фон → фото спикера → текстовые слои `{title}`, `{date}`, `{venue}`.

| Тариф | Что |
|-------|-----|
| Free | 3–5 шаблонов + водяной знак INUU |
| PRO / разово | Премиум шаблоны, ресайз 1:1 / 9:16 / A4 |

Рендер: HTML/CSS → screenshot (как Stories).

### Маркетинг B2B (платно)

- **Таргет-push** по сегменту (смотрели жанр, в избранном, не купили) — CPM 2–3 ₽/доставленное.
- **Буст** в выдаче / «радаре» — коэффициент ранга.
- **Аналитика PRO** — демография, кросс-интересы (подписка 1.5–3k ₽/мес).

### Промоутеры

- Уникальные deep links `?start=ref_*`.
- Скидка гостю + фикс/ % промоутеру.
- Сплит через ЮKassa (фаза 2).

## B2C EventPass (утверждено частично)

**Не делаем:** столы, такси.

**MVP подписки (~199 ₽/мес):**

1. Скидка от текущей волны (org opt-in «−15% для PRO»).
2. Без сервисного сбора на checkout.

**Позже:** early access 24 ч, снайпер-пуши, лёгкий возврат 100%.
