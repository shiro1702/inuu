## Типы контента в подборке

| `category_type` | Пример | В `curated_list_items` |
|-----------------|--------|-------------------------|
| `event` | Стендап 16.11 | `entity_type=event` |
| `promo` | Новое меню, акция до конца месяца | `entity_type=editorial_post` или `custom_block` |
| `custom_block` | Текст редакции без сущности | JSON block без `event_id` |

Парсер/Groq при ingest определяет `event` vs `promo` (нет жёсткой даты/времени → promo).

## Сборка подборки (менеджер)

### Фаза A — в чате (уже близко к `/pick`)

1. `/new_digest` → название черновика.
2. Под одобренными карточками: **«➕ В подборку»**.
3. `/view_digest` → список, удаление, обложка + вводный текст.
4. **Порядок:** кнопки ▲▼ или сообщение `3,1,2,4` (перестановка по индексам).

### Фаза B — Admin Mini App «тиндер» (рекомендовано)

- Лента событий Пт–Вс с `editorial_score >= 4`.
- Свайп вправо → в корзину; влево → skip; вверх → «главное событие».
- Drag-and-drop порядка → **Опубликовать** → `curated_lists` + items.

### Кастомные блоки

В корзине: **«➕ Промо»** — вкладка «сырой текст + Groq» или ручная форма (заголовок, текст, фото, ссылка).

## Автопилот (cron)

| Триггер | Логика | Черновик |
|---------|--------|----------|
| Чт 10:00 | События Пт–Вс, score ≥ 4 + 1–2 promo | `week-YYYY-wNN` |
| Календарь (14.02, 1.06…) | События/promo по тегам `#романтика`, `#дети`, `#лето` | slug праздника |
| После digest approve | «Одобрить все» → items в подборку периода | уже в 11 |

Менеджер только: открыть черновик → правки → **Опубликовать** + опционально SMM.

**Ранг ⭐1–5:** в авто-дайджест попадают 4–5; тройки — только общая лента.

## Stories и бот (матрица контента)

| Формат | Авто-источник | Канал |
|--------|---------------|--------|
| «Горит сегодня» | События сегодня вечером, top score | Stories + push 17:00 |
| Топ недели | Топ свайпов/избранного | Media group в боте |
| Место/промо дня | Случайный `promo` | Stories |
| Онбординг | 5–7 вечнозелёных слайдов | Stories раз в 3–4 дня |
| Микро-подборка | 3 карточки по тегу (#романтика) | Stories + кнопки в боте |

Рендер: **HTML/CSS страница → screenshot** (Puppeteer/Playwright), тексты сжимает Groq под лимит символов Stories.

Персональные дайджесты в боте — [12-afisha-tag-subscriptions.md](./12-afisha-tag-subscriptions.md); не дублировать массовый спам.

## SMM: Instagram карусели

1. Groq: длинный текст → ≤100 символов на слайд + эмодзи.
2. Роут `/story-render` (или аналог) — шаблон 1080×1920.
3. Архив PNG в TG менеджеру.

**Не в MVP:** полный «опубликовать везде одной кнопкой».
