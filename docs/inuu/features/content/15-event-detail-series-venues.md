# Карточка события: серии дат, места, источники

**Источник:** брейншторм [30.05.2026](../../../fix/brainstorm/30.05.2026.md) (29.05 08:55 – 30.05 08:26).

**Код:** `events.series_slug`, `recurrence`, `venue_id`, `content_submissions.source` — см. миграции 030–034.

---

## Модель: Parent + sessions

| Слой | Сущность | Пример |
|------|----------|--------|
| Parent | Одно «мероприятие» | Спектакль «Чайка», обложка, описание |
| Child | Сеансы / даты | 12.05 19:00, 13.05 19:00 |

В ленте — **одна карточка** на parent; внутри — chips дат или мини-календарь (если период / много дат).

### UI Mini App

- Горизонтальные chips: `[ 12 мая ] [ 13 мая ] …` — смена времени, цены, CTA «Купить».
- Длинная выставка: плашка «С 1 по 30 мая • выбрать день» → календарь.
- Sticky CTA внизу: цена + «Купить» / «Записаться».
- Блок **«Похожие»**: 3–4 события по пересечению `topic_tags` / `category_slug`.
- **«Позвать друга»** — share deep link (виральность).
- **Избранное** + push за сутки до сеанса из избранного.

## Парсинг расписания (Groq)

Единый блок `schedule` в payload (audio или текст канала):

```json
{
  "schedule_type": "single | specific_dates | period",
  "dates": ["2026-05-12T19:00:00+08:00"],
  "period_start": null,
  "period_end": null,
  "original_text": "фраза про даты из источника",
  "is_doubtful": false
}
```

**Правила промпта:**

- В system prompt — **текущая дата/время** (иначе «завтра» ломается).
- Пост со **несколькими разными** мероприятиями → `parse_kind=digest`, массив `events[]` — [11](./11-digest-parsing-and-curated-picks.md).
- Одно мероприятие, несколько дат → `single` + `recurrence.dates[]`.

**Модерация:** карточка с списком дат, флаг `is_doubtful`, кнопка **«Редактировать даты»** (Mini App).

После approve: 1 row `events` + N rows в `event_occurrences` / `recurrence.dates` (как в миграциях).

## Места и организаторы

| Поле | Назначение |
|------|------------|
| `venue_id` / place | Где проходит; клик → страница места + афиша venue |
| `organization_id` | Кто организует; подписка «на организатора» |
| `source_url` | Ссылка на пост TG/сайт — **обязательна** для parse |
| `source_kind` | `telegram_parse`, `bot_submit`, … |

**Промпт:** список известных площадок `id:name` → `place_id` или `null` (новое место на модерации).

**UX:** внизу карточки — «Источник: @channel» (лояльность каналам-донорам).
