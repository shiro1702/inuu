# Скрипт диалога: новости в Telegram-боте

Точные формулировки и шаги для `@inuu_bot`. Реализация: [04-telegram-bot-content-moderation.md](./04-telegram-bot-content-moderation.md).

**Поля в БД:** `editorial_posts` — `title`, `body`, `cover_media_url`, `slug`; опционально `post_type`, `linked_entity_type`, `linked_entity_id`, `is_sponsored`.

**Оплата партнёра:** [07-paid-news-publication.md](./07-paid-news-publication.md) — шаг тарифа и оплаты **после превью**, **до** модерации.

---

## Два сценария

| Сценарий | Команда | Кто | Оплата | После финала |
|----------|---------|-----|--------|--------------|
| Редакция | `/news` | Группа модерации | Нет | `editorial_posts`, `is_published = true` |
| Партнёр | `/submit` → «Новость / анонс» | `profiles` | Да (SKU) | `paid` → `pending` → модерация |

Команды: `/cancel`, `/done` (конец ввода текста).

---

## Сценарий A — редакция `/news`

Город по умолчанию: `ulan-ude`. Оплата пропускается (`payment_status = waived_editorial`).

### Шаг 0

```
Создаём новость для INUU · Улан-Удэ.

/cancel — отменить в любой момент
```

`[ Отмена ]` → `inuu:news:cancel`

### Шаг 1 — заголовок

```
Заголовок новости (до 120 символов)?
```

Валидация: 1–120 символов.

### Шаг 2 — тип

```
Какой это материал?
```

| Кнопка | `post_type` |
|--------|-------------|
| Новость | `news` |
| Обзор | `review` |
| Анонс места | `venue_announcement` |

`inuu:news:type:{news|review|venue_announcement}`

### Шаг 3 — обложка

```
Пришлите одно фото для обложки.
```

`[ Пропустить ]` → `inuu:news:cover:skip`

### Шаг 4 — текст

```
Текст для читателей.

Можно отправить несколько сообщений подряд.
Когда закончили — отправьте /done
```

Валидация: 30–4000 символов суммарно.

### Шаг 5 — привязка

```
Привязать к карточке на сайте?
```

`[ Заведение ]` `[ Событие ]` `[ Без привязки ]`

Поиск → inline `inuu:news:venue:{id}` / `inuu:news:event:{id}`

### Шаг 6 — превью

```
─── Превью ───
📰 {post_type_label}
{title}

{body_preview}

Привязка: {venue | event | —}
/ulan-ude/guides/{slug}
```

`[ Изменить заголовок ]` `[ Изменить текст ]` `[ Опубликовать ]` `[ Черновик ]`

### Шаг 7

```
✅ Новость опубликована.

{app_url}/ulan-ude/guides/{slug}
```

## Сценарий B — партнёр `/submit` → новость

### Шаг 0

```
Что хотите разместить в INUU?
```

`[ Событие ]` `[ Мастер-класс ]` `[ Новость / анонс ]`

`inuu:submit:kind:{event|masterclass|news}`

### Шаги 1–4

1. Заголовок (до 120 символов)  
2. Обложка — при skip: «Без фото заявку могут вернуть на доработку.»  
3. Текст + `/done`  
4. Место: `[ Заведение ]` `[ Адрес текстом ]` `[ Не привязано ]`

При дате в тексте — уточнение: `[ Оставить новостью ]` `[ Создать событие ]`

**Не спрашиваем:** дату/время события, цену билета, количество мест.

### Шаг 5 — превью

```
─── Проверьте заявку ───
📰 Новость / анонс
{title}

{body_preview}

Место: {venue | address | —}
```

`[ ✏️ Изменить ]` `[ Далее: тариф ]` `[ ❌ Отменить ]`

### Шаг 5b — тариф и оплата

См. [07-paid-news-publication.md](./07-paid-news-publication.md).

```
Размещение для партнёров — платное.

[ Базовый — 3 000 ₽ ]
[ Стандарт — 7 000 ₽ ]
[ Пакет «Выходные» — 12 000 ₽ ]
[ Счёт для юрлица ]
```

После успешной оплаты:

```
✅ Оплата получена.
Заявка #{short_id} отправлена на модерацию (обычно 1–2 рабочих дня).

/my_submissions — статус заявок
```

### Ответы при модерации

**Одобрено:**

```
✅ Заявка #{short_id} опубликована.

{app_url}/ulan-ude/guides/{slug}
```

**Отклонено:**

```
Заявка #{short_id} не опубликована.

Причина: {reason_label}
{reject_comment}

{политика возврата — см. 07}

/submit — новая заявка
```

**Доработка:**

```
Редакция просит доработать заявку #{short_id}.

{comment}

[ ✏️ Исправить заявку ]
```

`inuu:submit:resume:{submission_id}` — без повторной оплаты, если уже `paid`.

## Команды меню

```
start - Главное меню
submit - Подать заявку
my_submissions - Мои заявки
help - Помощь
news - Создать новость (редакция)
event - Создать событие (редакция)
```
