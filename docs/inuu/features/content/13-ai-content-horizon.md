# AI за пределами парсинга: горизонт возможностей

**Источник:** брейншторм [30.05.2026](../../../fix/brainstorm/30.05.2026.md) (вопросы 29.05 07:03, 07:21).

**Статус:** roadmap / гипотезы. Базовый конвейер — [08-event-sourcing-and-moderation-pipeline.md](./08-event-sourcing-and-moderation-pipeline.md).

---

## Принцип

Один стек: **Groq (текст, дёшево)** + при необходимости **Vision** (афиша ↔ текст) + позже **Gemini Flash** для vision free tier. Меняются **system prompt** и **точка вызова**, не архитектура БД.

---

## Направления

| # | Направление | Что делает | MVP? |
|---|-------------|------------|------|
| 1 | **Редакция / SMM** | Из N событий JSON → пост «куда на выходных» для TG-канала | P2 (после стабильного ingest) |
| 2 | **AI-консьерж в боте** | NL-запрос → фильтры → 2–3 карточки + ответ человеческим языком | P2 (ограниченный NL или кнопки) |
| 3 | **Рерайт описаний** | Сухой анонс → продающий `description` при парсинге | P1b (флаг в payload) |
| 4 | **Вайб-теги** | Скрытые теги: `#для_свидания`, `#с_детьми` — поиск по настроению | P2 |
| 5 | **Vision B2B** | Организатор кидает фото афиши → черновик события | P2 (после шаблонных афиш) |

---

## Стратегия «Дерево» (каналы и ToV)

**Ствол (сейчас):** один бот + один нейтральный TG-канал + Mini App. Отладить ingest, модерацию, теги.

**Ветки (позже):** нишевые каналы («Тусовки», «С детьми») — те же `events` из БД, разные промпты Groq для текста поста. Маркетинг дороже, лояльность выше.

Не плодить отдельные боты до стабильного ядра.
