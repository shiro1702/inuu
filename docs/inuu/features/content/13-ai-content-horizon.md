## Принцип

Один стек: **Groq (текст, дёшево)** + при необходимости **Vision** (афиша ↔ текст) + позже **Gemini Flash** для vision free tier. Меняются **system prompt** и **точка вызова**, не архитектура БД.

## Стратегия «Дерево» (каналы и ToV)

**Ствол (сейчас):** один бот + один нейтральный TG-канал + Mini App. Отладить ingest, модерацию, теги.

**Ветки (позже):** нишевые каналы («Тусовки», «С детьми») — те же `events` из БД, разные промпты Groq для текста поста. Маркетинг дороже, лояльность выше.

Не плодить отдельные боты до стабильного ядра.
