### 2. Поддержка и инциденты на входе

### 3. Технические лимиты и хранение

| Тема | Решение MVP |

| Гео | **Только Улан-Удэ**; 50+ событий на выходные в городе важнее охвата РФ |

## Must Have vs Cut (резюме брейншторма)

### ✅ Делаем (Must Have)

- Cron-парсер + AI на 10–15 главных сайтов **города**
- Теневые профили организаторов + claim
- Mini App: каталог + корзина + мои билеты ([21](./21-mini-app-and-web-wireframes.md))
- ЮKassa split + hold 15 мин
- Генератор афиш: 2–3 шаблона ([19](./19-organizer-lk-monetization.md))
- Сканнер билетов
- AI санитар + TL;DR ([22](./22-ai-bot-concierge-and-intent.md))

- PRO-подписка B2C
- Автовозвраты 193-ФЗ с калькулятором
- Сложный редактор афиш
- Dynamic pricing по загрузке зала (волны цен — ок, см. [18](./18-ticketing-full-flow.md))

## Лимиты free-tier (когда упрёмся)

| Сервис | Улан-Удэ ~1–3k MAU | Bottleneck? |
|--------|-------------------|-------------|
| **Supabase** | 500 MB, 50k MAU | 🟢 Нет (текст лёгкий; следить за Storage) |
| **Vercel Hobby** | 100 GB/mo, fn 10 s | 🟡 Voice + Groq у грани таймаута → async ACK |
| **Groq free** | ~30 RPM, ~30k TPM | 🔴 **Да** — пятница 18:00, 10+ NL-запросов/мин |

### Groq: архитектура выживания

1. **8b** — intent; **70b** — только финальный текст.
2. В промпт ≤5 событий после SQL-фильтра.
3. Кеш текстов «рулетки» на пятницу.
4. **Graceful 429:** «Перегрелся 🔥 — открой Афишу» + Mini App button.

PMF-сигнал: частые 429 вечером → пора платный API Groq/OpenAI.

### Supabase «спячка»

Free project sleep после 7 дней без запросов — бот + cron держат активность; опционально ping cron на Vercel.
