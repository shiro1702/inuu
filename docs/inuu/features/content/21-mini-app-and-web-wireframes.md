## Принцип

Два интерфейса, одна БД:

| Интерфейс | Задача |
|-----------|--------|
| **Telegram Mini App (TMA)** | Мобильные покупки, билеты, быстрый каталог |
| **Веб-сайт** | SEO, десктоп, B2B-витрина организаторов |

Покупка на сайте без авторизации → модалка с QR / deep link в бота (перелив трафика в экосистему TG).

## Telegram Mini App

**Bottom Tab Bar (3–4 вкладки):** Главная | Поиск | Билеты | Профиль.

### Экран: Главная

Задача — ответ «куда сегодня / на выходных» за ~3 секунды.

| Блок | Содержание |
|------|------------|
| Header | Приветствие, выбранный город, иконка поиска |
| Highlights («сториз») | Подборки: «На выходных», «Бесплатно», тематические (техно, театр…) |
| Быстрые фильтры | Таблетки: Сегодня, Завтра, Выходные, категории |
| Лента | Карточки событий |

**Карточка события:** сжатая афиша, название, дата/время, место, цена («от N ₽» / «Бесплатно»).

**Native vs parsed (критично для MVP):**

| Тип | CTA |
|-----|-----|
| `native` (наша продажа) | Яркая кнопка **🎟 Купить билет** |
| `parsed` (агрегатор) | Спокойная **🌐 На сайт** (внешняя ссылка) |

Визуально: native можно подсветить градиентом или значком ⚡.

### Экран: Событие

- Обложка, название, дата, адрес (тап → карта / Яндекс.Навигатор).
- Кликабельный организатор / площадка → [теневой профиль](./17-ingest-sources-context.md).
- Описание под «Читать далее»; опционально **TL;DR + vibe** из [13-ai-content-horizon.md](./13-ai-content-horizon.md).
- **Sticky bottom bar:** выбор категории билета → **[ Оплатить N ₽ ]**.

### Экран: Организатор / площадка (теневой профиль)

- Аватар, название, адрес, описание.
- **[ Подписаться на анонсы ]** → push по новым событиям площадки.
- Список предстоящих событий.
- Внизу: **«Вы владелец? Забрать профиль»** → claim flow.

### Экран: Мои билеты

Вкладки: **Активные** | **Прошедшие**.

Активный билет: название, место, дата, **крупный QR**; автояркость экрана 100%.

Кнопки: **[ Поделиться ]** → [28](./28-omnichannel-share-and-tma-funnel.md) (`useShare`), **[ Поддержка / Возврат ]** → [23-bot-roles-ops-support.md](./23-bot-roles-ops-support.md).

## Веб-сайт

### Главная

| Блок | Содержание |
|------|------------|
| Header | Логотип, город, поиск; **[ Создать событие ]**, **[ Войти в Telegram ]** |
| Hero | «Все события города в одном месте»; строка поиска (что + когда); QR в Mini App |
| Каталог | Плитка 3–4 в ряд; сайдбар: цена, дата, категория |
| Площадки | Карусель теневых профилей |
| B2B | «Вы организатор?» — комиссия 4%, ИИ-афиши, выплаты; **[ Зарегистрировать ЛК ]** |
| Footer SEO | Облако тегов; ссылки на оферту, ПД, контакты |

### Checkout (общий с TMA)

1. Выбор кол-ва билетов.
2. **Таймер hold:** «Билеты забронированы на 14:59» ([18](./18-ticketing-full-flow.md)).
3. Форма (новые юзеры): имя + email (чек ОФД); автоподстановка для повторных.
4. Чекбокс: согласие с офертой платформы и организатора.
5. WebView ЮKassa (SberPay, СБП, карты).
6. Успех: конфетти + «Открыть билет».

## MVP scope

| Делаем | Не делаем в MVP |
|--------|-----------------|
| 4–5 экранов TMA + главная сайта | Сложный редактор афиш |
| Native vs parsed CTA | PRO-подписка B2C |
| Checkout + hold 15 мин | Динамическое ценообразование по загрузке зала |
| QR в «Мои билеты» | Полный калькулятор возвратов 193-ФЗ (→ чат поддержки) |
