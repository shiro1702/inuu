# Карусели — руководство для редакции

**Тест:** [inuu-topaz.vercel.app/dashboard/carousel-studio](https://inuu-topaz.vercel.app/dashboard/carousel-studio) (нужен вход в кабинет). **Прод:** [inuu.ru/dashboard/carousel-studio](https://inuu.ru/dashboard/carousel-studio).

## С чего начать

### Вариант A: Carousel Studio (классика)

1. Открой **Дашборд → Карусель для соцсетей** (`/dashboard/carousel-studio`).
2. Выбери город и источник:
   - **Вручную** — пустой проект;
   - **События** — чекбоксы из афиши;
   - **Подборка** — curated list;
   - **Статья / заявка** — если перешли по deep link.
3. Настрой шаблон, vibe, aspect.
4. Скачай PNG или опубликуй в editorial.

### Вариант B: Carousel Editor (share link)

1. В Studio нажми **«Новый проект + share link»** — или открой существующий по ссылке `/dashboard/carousel/edit/[id]`.
2. Редактируй на телефоне как Stories: свайп слайдов, bottom sheets.
3. **Сохранить** — в БД. **Поделиться** — копирует URL коллеге.

## Генерация с ИИ

### Вся карусель

1. В редакторе нажми **«Текст»** в нижней панели (или «Импорт текста» в списке слайдов).
2. Режим **«ИИ (Groq)»**.
3. Вставь текст анонса или выбери quick prompt (концерт / гастро / подборка).
4. **«Сгенерировать карусель»** — заменит все слайды.

Альтернатива без ИИ: режим **«Разбить текст»** — разделители `---` или нумерация `1. … 2. …`.

### Один слайд

1. Открой **редактирование слайда** (кнопка «Текст» или карандаш в списке слайдов).
2. Блок **«ИИ (Groq)»** → **«Сгенерировать»**.
3. Опиши контент для **этого** слайда (обложка / тезисы / CTA).
4. **«Сгенерировать слайд»** — обновит только текущий слайд.

> Стикеры, которые вы уже расставили вручную, при перегенерации слайда **сохраняются**.

---

## Ручное редактирование слайда

В sheet «Редактировать слайд»:

| Роль | Поля |
|------|------|
| Обложка | Заголовок, фото (URL или загрузка) |
| Контент | Заголовок, тезисы (по строке), фото |
| Финал | CTA-текст |

---

## Стикеры

1. Нижняя панель → **«Стикеры»**.
2. Выбери из библиотеки — стикер появится в центре слайда.
3. На холсте:
   - **1 палец / мышь** — перетаскивание;
   - **2 пальца** — масштаб и поворот;
   - **колесо мыши** — масштаб (десктоп);
   - **Shift + drag** — поворот (десктоп).

---

## Стили и форматы

Кнопка **«Стили»** в шапке:

- **Шаблон** — один из 8 style packs;
- **Vibe** — градиент / настроение;
- **Aspect** — 4:5 (лента), 9:16 (Stories), 1:1, 16:9;
- **Тип проекта** — carousel / post / story / cover;
- **Ссылка** — для QR на outro-слайде.

---

## Шаблоны пользователя

1. **«Шаблоны»** в нижней панели.
2. **Сохранить** — запомнит layout + theme текущего проекта.
3. **Применить** — подставит layout к новому контенту.
4. Groq fill (через API) — обновит только тексты, координаты стикеров не трогает.

## Экспорт и Telegram

| Действие | Где |
|----------|-----|
| Скачать PNG всех слайдов | **«Скачать PNG»** внизу редактора |
| Отправить в TG | **«Отправить в TG»** → выбор чата → очередь |
| Скопировать ссылку на проект | **«Поделиться»** в шапке |
| Текст поста для TG | поле `telegram_post_text` после Groq-генерации |

PNG рендерится в браузере в полном разрешении (1080 px по длинной стороне).

---

## Советы

- Для подборки из 3–5 событий используйте Studio → события — Groq сожмёт тексты автоматически.
- Обложке помогает короткий яркий заголовок; детали — на body-слайдах.
- На outro добавьте ссылку в «Стили» — появится QR.
- Сохраняйте проект перед «Поделиться» — share link работает только с `id` в БД.
