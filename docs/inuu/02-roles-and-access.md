# Роли и доступ

## Матрица ролей

| Роль | Кто | Основные действия |
|------|-----|-------------------|
| **Гость** | Не авторизован | Просмотр каталога, поиск, stories, запись через WhatsApp / «Хочу пойти» |
| **Клиент** | Зарегистрированный пользователь | Избранное, история записей/заказов, отзывы, уведомления, оплата |
| **Мастер** | Самозанятый / ИП (beauty, кондитер) | Расписание, услуги, портфолио, горящие окна, финансы, ответы на отзывы |
| **Салон / организация** | Юрлицо или сеть | Несколько мастеров, филиалы, общая админка, реквизиты |
| **Организатор событий** | МК, концерты, лекции | События, слоты, билеты, отчёт по продажам |
| **Владелец заведения** | Бар, кафе, ТЦ | Профиль venue, привязка событий, stories, отзывы |
| **Рекламодатель** | Любой B2B | Кампании, баннеры, статистика показов/кликов |
| **Редакция** | Контент-команда города | Новости, подборки, модерация, stories редакции |
| **Платформенный админ** | Владелец продукта | Города, тарифы, споры, глобальная аналитика |

## Личные кабинеты

### Клиент

- Профиль: имя, телефон, email, привязка Telegram.
- **Записи и заказы:** предстоящие / прошлые (beauty, события, кондитер).
- **Избранное:** места, события, мастера, заведения (теги для будущих рассылок).
- **Интересы:** категории (красота, еда, искусство, туры) — для персонализации пушей.
- **Уведомления:** каналы (email, Telegram), типы (напоминания, акции, избранное).
- **Оплаты:** история, чеки (когда подключена касса).

### Мастер / салон (beauty)

- Профиль и услуги с ценами.
- **Расписание:** слоты, привязка к одному или нескольким салонам.
- **Записи:** календарь день/неделя, подтверждение / отмена.
- **Лист ожидания:** очередь на дату/мастера, уведомление при освобождении слота.
- **Горящие окошки:** создание оффера с `expires_at`.
- **Портфолио:** фото работ (Media Library).
- **Отзывы:** просмотр, ответ (опционально).
- **Финансы:** баланс, вывод (после подключения эквайринга и холда).

### Кондитер

Всё из beauty **плюс**:

- **Под заказ:** начинки, оформление, загрузка референса, комментарий.
- **Готовая продукция:** категории, теги, количество в упаковке, остатки.
- **Календарь выдачи:** заказы на месяц/неделю со временем самовывоза/доставки.
- **Выкуп:** статусы «забронировано / выдано / отменено».
- **Выплаты:** сколько на балансе, доступно к выводу.

### Организатор / venue

- CRUD событий, квоты мест, цены билетов.
- Привязка к `venue_id`.
- Список записавшихся / оплативших.
- Промо в stories (при модерации).

### Рекламодатель

- Создание кампаний: баннер, место (главная / категория / stories).
- Бюджет, период, таргет по `city_id` и категориям.
- Статистика: показы, клики, CTR.
- Счета и акты (фаза 2).

### Редакция / админ города

- Модерация: новые мастера, отзывы, спорные заказы.
- Новости и подборки (без парсинга RSS на MVP).
- Управление событиями и venues (или апрув заявок партнёров).
- Stories редакции и «выбор редакции».
- Рассылки (позже): сегменты по интересам / избранному.

## Авторизация (приоритет каналов)

1. **Telegram Login** — основной (без пароля, база для бота).
2. **Телефон + SMS** — опционально для напоминаний.
3. **Email** — резерв, рассылки.

На MVP допустимо: запись без ЛК → привязка Telegram/MAX при первой оплате/записи (`profiles` + `initData`).

Реализация в репо: Supabase `profiles`, [TELEGRAM_AUTH_VIA_BOT_RU.md](../features/TELEGRAM_AUTH_VIA_BOT_RU.md), `useTelegram.ts`.

## RBAC (кратко)

| Действие | Клиент | Мастер | Org owner | Editor | Platform |
|----------|--------|--------|-----------|--------|----------|
| Создать отзыв | ✓ | — | — | модерация | ✓ |
| Редактировать свой профиль | ✓ | ✓ | ✓ | — | ✓ |
| Чужой профиль | — | — | — | ✓ | ✓ |
| Финансы точки | — | ✓* | ✓ | read | ✓ |

\*Мастер видит только свои слоты и выплаты; владелец org — все филиалы.

## Универсальный Telegram-бот `@inuu_bot`

Один бот на платформу, контекст в payload:

- Напоминания о записи / билете.
- Статусы заказа кондитера.
- Горящие окошки по подписке на категорию.
- Лист ожидания: «освободилось место — подтвердить за 30 мин».
- Для партнёра: «новая запись 14:00».

Каждое сообщение содержит: **город • бренд • точка • № заказа**.
