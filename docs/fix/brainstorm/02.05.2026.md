## Решения (зафиксировать в каноне)

| Решение | Деталь |
|---------|--------|
| Категории **не убираем** | Одна жёсткая категория + до 5 тегов |
| Вайбы = теги в БД | Одна колонка / массив `topic_tags`, группы только в UI и seed |
| Видео-хостинг | Max (не Telegram CDN в РФ); до 15–30 с; UI как Stories |
| Рилсы MVP | Партнёрка блогеров, не парсинг Instagram; карусель / карточка venue |
| Весь контент на одних тегах | Events, editorial, lists, stories наследуют вайбы для фильтра |
