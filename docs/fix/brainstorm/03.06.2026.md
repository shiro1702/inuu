## Решения (зафиксировать в каноне)

| Решение | Деталь |
|---------|--------|
| Контент = retention | Каталог мест быстро надоедает; журнал / медиа внутри приложения — ежедневный return |
| Два типа привязки | Редакция портала (`shop_id` editorial) **или** жёсткая связь с venue/org |
| Воронка UI | Stories (кликбейт) → лонгрид → «читать потом» → бот в выходные |
| Напоминания | Не навязчиво: пятничный дайджест, контекст по place, 24ч только для hot news |
| Groq в manager chat | 90% рутины AI; админ жмёт «Одобрить» в Telegram |
| Карусели | **HTML + Tailwind** → `html-to-image` (клиент) / satori (бот); не Canva |
| Видео | **Client-side only** — WebCodecs + mp4-muxer + GSAP; сервер не рендерит |
| Доставка | Персональные карусели в TG только по **opt-in вайбам**; кнопка «Меньше такого» |
| Расширение 30 | Пайплайн [30-manager-chat-place-editorial.md](../../inuu/features/content/30-manager-chat-place-editorial.md) — база; 33–36 — следующая волна |
