## Решения (зафиксировать в каноне)

| Решение | Деталь |
|---------|--------|
| Mobile-first | Референс **Instagram Stories** — жесты, bottom sheets, зона большого пальца; без боковых панелей |
| Старт UX | **AI-first** (Groq за 5 с) → точечная доработка на холсте (Вариант 1 + элементы 2) |
| Три роли слайда | `first` (cover) / `middle` (content) / `last` (CTA) — разные HTML-шаблоны, один theme pack |
| Персистентность | Pinia + `pinia-plugin-persistedstate`; shareable state → `generated_carousels` в Supabase |
| Groq + шаблон | **Комбо:** semantic `role` на текстовых блоках + fallback «слепое копирование» JSON |
| Вёрстка холста | **Flow stack** (заголовок → описание) + **Absolute satellites** (стикеры, бейджи) с `anchor` + `zIndex` |
| Координаты | **Virtual canvas** (1000×1000 усл. ед.) — масштаб на preview и export без потери |
| Афиша = 1 слайд | Тот же движок; aspect `9:16` / `1:1` / `4:5` / `16:9` |
| TG доставка | Гибрид: партнёр → ЛС; менеджер → moderation chat; **очередь** `telegram_queue`, не прямой send |
| Не дублировать 3d | HTML-шаблоны и PNG-рендер из [35](./35-html-carousel-video-studio.md) — **расширяем**, не переписываем |
