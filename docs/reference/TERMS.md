# Словарь терминов INUU

Единообразие терминов в продукте **INUU**, документации и интерфейсах.

## Продукт

| Термин | Значение |
|--------|----------|
| **INUU** | Городской лайфстайл-агрегатор (афиша, места, запись, туризм) |
| **Город** | Тенант верхнего уровня (`cities`, URL `/{city_slug}`) |
| **Организация** | B2B-аккаунт партнёра (`shops` → `organizations`: салон, организатор, кондитер) |
| **Точка / venue** | Физическое место на карте (`venues`; legacy таблица `restaurants`) |
| **Событие** | Афиша: концерт, МК, вечеринка (`events`) |
| **Запись / booking** | Бронь услуги, билет, заявка (`bookings`; не «заказ еды») |
| **Редакция** | Контент города: подборки, stories, обзоры |

## Правила UI

### Dashboard (партнёр)

- **Организация** — настройки бренда и команды.
- **Точка** — филиал/студия/площадка (не «ресторан»).
- **Записи** — список bookings (не «заказы» с кухней).
- **Услуги** — каталог слотов beauty / кондитера (не «меню» с блюдами).

### Витрина (клиент)

- **Город** — в шапке и SEO.
- **Место** / **заведение** — карточка venue.
- **Событие** — афиша с CTA «Иду» / «Билет».
- **Мои записи** — история bookings.

## Техническая ремарка

- В БД пока могут встречаться legacy-имена: `shops`, `restaurants`, `orders`.
- Новый код и миграции — имена INUU: `organization_id`, `venue_id`, `booking_id`.
- Не использовать в новых текстах: PocketMenu, QR-меню, корзина блюд, кухня, филиал-ресторан (кроме миграции данных).

## Legacy (не использовать в новых фичах)

| Устаревшее | Замена INUU |
|------------|-------------|
| Ресторан (в смысле меню еды) | Место / venue |
| Заказ (еда) | Запись / booking |
| Меню (блюда) | Услуги / билеты |
| Филиал (HoReCa) | Точка |
| Tenant slug → cart | `/{city_slug}/events/...` |
